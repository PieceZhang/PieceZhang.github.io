## STM32 CAN Driver for RoboMaster Motors

This embedded project uses the RoboMaster Type C development board and the CAN bus to control M3508, M2006, and GM6020 motors. It updates the official example implementation from the STM32Cube firmware 1.18.0 API to version 1.25.0 while retaining interrupt-based CAN reception.

The repository provides a CubeMX project, driver sources, and an MIT-licensed reference implementation for robotics and embedded-control projects.
