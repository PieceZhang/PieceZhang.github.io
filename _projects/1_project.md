## US-PPNR: A Multimodal Dataset for Autonomous Probe Placement and Needle Retrieval

**November 2025 - February 2026**

US-PPNR contains **2,546 synchronized trajectories (10.9 hours)** for robotic ultrasound probe placement and needle retrieval in liver-biopsy workflows. The dataset was contributed to [NVIDIA Open-H-Embodiment](https://open-h.github.io/open-h-embodiment/), an open-source healthcare robotics dataset initiative.

My contributions included task design, UR5e robot path planning, ROS framework development, and fine-tuning Qwen 2.5-VL-based vision-language-action models for probe placement and needle retrieval.
